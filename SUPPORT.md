# Support

OSS Careboard is maintained as a small open-source project.

## Getting help

1. Read the [README](README.md) and [cost boundary](COST.md).
2. Search existing GitHub issues.
3. Open a bug report or feature request with a minimal reproduction.

For bugs, include the command or Action inputs used, Python version, expected
behavior, actual behavior, and any non-sensitive error output.

## Security and privacy

Do not post tokens, private repository snapshots, private issue titles, or
other confidential data in a public issue. Follow [SECURITY.md](SECURITY.md)
for vulnerability reports.

## Scope

Support is best effort. The project does not provide an uptime guarantee,
managed hosting, paid API credits, or private-repository access.
